# WhatCanUDo 작업 이름 라틴 문자로 바꾸기 (2026-09-26, 사용자 지시로 중단)

영어 모드에서 □ 로 깨지는 한글 이름 작업 18개(Land Race 3 + Deathmatch 15)를 Creator 에서 "Warp <지역>" 으로 바꾸는 작업. 5개 완료, 1개 실패, 12개는 사용자가 21:10 에 미루자고 해서 남김.
즐겨찾기 11~17(Large Warehouse·Clubhouse×2·Vehicle Warehouse·MOC Interior·Hangar·Avenger Interior)은 Apse18 이 만든 Capture 이고 이름이 이미 라틴 문자라 대상이 아니다.

## 실측
- 재퍼블리시 = **같은 작업 갱신**. Creator → Load Creation → Published 에서 불러와 Deathmatch Details → Title 을 고치고 Update Version 을 누르면 "VERSIONED — A new version of '…' has been published." 목록 개수 28개 그대로, 옛 이름은 사라지고 Last Updated 만 바뀐다. 테스트 불필요(5건 모두).
- 제목 최대 25자.
- Esc 를 안 쓰는 경로: Details 같은 하위 메뉴에서 뒤로가기는 Backspace. **Published 목록에서는 Backspace 가 Delete 이므로 절대 누르지 않는다**(목록에서는 앞으로만 간다).
- 목록은 알파벳순: 라틴 10개(Fingerprint 1~3·Penthouse·Plasma 1~3·Torch 1~3 Helmet) → "Warp …" 블록 → 한글 블록. 한글 블록 첫 행 = 11 + (완료 수) 번째 행.
- 한 건 약 2.5분. 키 순서: 행 Enter → 9초 → M → Enter(Details) → Enter(Title, 따로 보내야 먹음) → Backspace×30 → 타이핑 → Enter → Backspace → Down×4 → Enter(Update Version) → Enter → Down → Enter(Exit) → Enter(확인) → Creator 메뉴.
- Creator 진입: 일시정지 → ONLINE → Rockstar Creator → "quit this session" 확인. 나가기: Creator 메뉴 → Quit to GTA Online(9번째) → 확인 → 약 75초 뒤 프리모드(마지막 위치인 아케이드 안). 세션 종류는 새로 잡히므로 F5 두 번으로 초대 전용으로 옮겼다.
- 지도 표시(「GTA 작텔·매크로 세션 이어받기」 19:33~19:55 실측): 남이 만든 즐겨찾기 작업은 프리모드 지도에 안 뜬다(범례 83종 중 제작자 줄은 WhatCanUDo 둘뿐). WhatCanUDo 작업 28개는 전부 뜬다.
