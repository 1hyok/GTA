# 통화 종료 아이콘 회귀 화면

1920×1080 화면의 기존 종료 아이콘 검색 영역에서 x=1728, y=994, w=173, h=65만 잘랐다. 사용자 이름과 채팅은 포함하지 않는다.

- `live-call-end.png`: 2026-10-07 19:30:31 KST 실제 데스크톱 캡처, 레스터에게 전화 연결 중. 기존 템플릿과 최소 채널 오차 55.
- `recorded-call-end.png`: 같은 날 18:39:01 무렵 Steam 녹화, MCT에서 일어선 뒤 레스터 통화가 연결된 상태. 기존 템플릿과 최소 채널 오차 12.
- `no-phone.png`: 같은 날 19:30:41 실제 데스크톱 캡처, 전화기가 사라진 서비스 메뉴. 통화 아이콘이 없다.

`test-phone-call-template.ps1`은 각 PNG의 실제 픽셀 오차를 구한 뒤 프로덕션 `EarnSeen()`의 허용치로 판정한다. 게임 입력이나 화면 표시 없이 실행한다.
