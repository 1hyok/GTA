# 프레임 급락 증거 감시

실행 중인 `%USERPROFILE%\scripts\gta-turbo.ps1`의 `%LOCALAPPDATA%\gta-perf\yyyyMMdd.csv` 기록을 재사용한다. 기존 기록기가 실행 중이어야 FPS를 판단할 수 있다. 새 감시는 게임 키·클릭·포커스·설정·프로세스 종료를 수행하지 않는다.

`install.ps1`을 실행하면 현재 사용자 시작프로그램 바로가지를 저장하고 숨김 창으로 감시를 시작한다. 중복 실행은 mutex로 차단한다. Main과 기존 FPS 기록기는 재시작하지 않는다. 중지는 `status.json`의 `watcher_pid`에 해당하는 감시 프로세스만 종료하고 시작프로그램의 `GTA Frame Evidence.lnk`를 제거한다.

기록 위치는 `%USERPROFILE%\gta-perf\frame-watch`다. `status.json`의 시각·원본 해시·FPS 공급 상태·메모리 조회 오류를 통해 실제 작동을 확인한다. 날짜별 JSONL에는 약 5초마다 현재 게임 PID/실행 시각, 전면 PID, FPS 원본 시각, GPU 전용·공유·총 커밋 메모리(어댑터별 바이트), 기존 GPU 온도·전력·클럭 기록을 함께 저장한다. 데이터가 없거나 조회에 실패하면 오류로 남기며 0으로 처리하지 않는다. `foreground.jsonl`에는 전면 변경을 기록한다. 관측은 약 0.75초 주기이므로 그보다 짧은 포커스 전환은 놓칠 수 있다.

게임 전면 상태를 20초 이상 연속 관측했고 FPS가 30초 이내 자료일 때만 감지에 사용한다. 게임 재시작 시 기준을 초기화한다. 처음 6개의 유효 FPS로 기준을 만들고 최근 정상 표본 최대 30개의 중앙값을 사용한다. 기준이 50 FPS 이상이고 40% 이상이면서 20 FPS 이상 떨어진 새로운 표본이 3번 연속 들어오면 급락 후보를 기록한다. 기존 FPS 기록 간격 기준 약 40초의 지속 저하를 포착하며 짧은 끊김 전체를 감지하는 도구는 아니다. 로딩이나 장면 변화도 후보에 포함될 수 있다.

`incidents/시각/`에는 직전 최대 2분과 이후 2분의 표본, 전면 변화, 기준값과 원본 해시를 보존한다. 사건 이후 PresentMon으로 해당 게임 PID의 15초 원시 프레임 자료도 수집한다. 별도 ETW 세션과 숨김 프로세스를 사용하며 다른 측정 세션을 중지하지 않는다. 25초 내 종료되지 않으면 자신이 시작한 측정 프로세스만 종료한다. `capture.json`의 `usable`과 행 수를 확인해야 실제 프레임 자료 확보 여부를 알 수 있다. 저하가 계속되는 동안 사건을 반복 생성하지 않으며 정상의 80% 이상인 새 표본 3개로 회복된 후 다시 감지한다. `alerts.jsonl`은 사건 색인이며 팝업이나 외부 메시지를 보내지 않는다.

이 자료는 원인 확정이나 재발 방지 완료를 의미하지 않는다. 공유 메모리 사용 자체가 VRAM 부족을 증명하지 않으며, 관리자 권한이 필요한 커널 GPU 메모리 퇴거 추적은 포함하지 않는다. Steam 영상은 이 도구가 복사하거나 재생하지 않는다. 기록 파일은 조사 근거를 보존하기 위해 자동 삭제하지 않는다.

입력 없는 회귀검사는 `frame-watch.tests.ps1`, 실제 읽기·저장 확인은 별도 출력 경로로 `frame-watch.ps1 -RunSeconds 20 -OutputDirectory <경로>`를 사용한다.
